# Retratos de personajes

Coloca aquí los retratos que estarán disponibles en el primer paso del creador.

- Formato recomendado: WebP o PNG.
- Tamaño recomendado: 512 × 512 px.
- Un personaje por archivo.
- Usa nombres descriptivos.

Después de subir las imágenes, agrega sus rutas `/images/character-creation/portraits/nombre-del-archivo.webp` al arreglo `BUILDER_PORTRAITS` en `src/App.svelte` para que aparezcan en la galería.

La carpeta `classes/` está reservada para las ilustraciones de las doce clases.
