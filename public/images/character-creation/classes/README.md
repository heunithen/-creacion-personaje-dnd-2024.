# Retratos de clase

Coloca aquí los retratos PNG de las doce clases. La interfaz del creador utilizará estas rutas relativas desde la raíz pública del sitio:

- barbaro.png
- bardo.png
- brujo.png
- clerigo.png
- druida.png
- explorador.png
- guerrero.png
- hechicero.png
- mago.png
- monje.png
- paladin.png
- picaro.png

Formato recomendado: PNG cuadrado de 512 × 512 px, con el personaje centrado y sin texto incrustado.

Cuando se incorporen los archivos, se conectarán a las tarjetas de selección de clase. No es necesario modificar sus nombres si se mantienen exactamente estos nombres de archivo.
